# FNAF Save Manager 

**Created by:** K_F_

A powerful, user-friendly save editor built with Python and PySide6. This tool allows you to easily modify your progress across the **first 6 Five Nights at Freddy's games plus Ultimate Custom Night (UCN)**. Unlock nights, stars, certificates, and hidden easter eggs with just a few clicks!

---

## 🌟 Features
* **Full Game Coverage:** Supports FNAF 1, 2, 3, 4, Sister Location, Freddy Fazbear's Pizzeria Simulator (FNAF 6), and UCN.
* **Unlock Everything:** Easily unlock all nights, maximum stars, and completion certificates.
* **Easter Eggs & Extras:** Toggle hidden features and minigames within the save files.
* **Modern UI:** Clean and intuitive graphical interface powered by PySide6.

---

## 🚀 Future Updates (Roadmap)
We are actively working on expanding the capabilities of the FNAF Save Manager. Coming in future releases:

* **FNAF World Support:** Direct modification and management of FNAF World save data directly from its directory.
* **Exact Checkpoint Saving:** Advanced save-state features allowing you to save at exact moments or checkpoints *between* or *during* nights (especially useful for complex sequences in **FNAF Sister Location**).
