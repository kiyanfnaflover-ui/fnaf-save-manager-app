# 🐻 FNAF Save Manager & Editor

**Created by:** K_F_

Welcome to the ultimate **FNAF Save Manager**, a powerful and user-friendly save editor built with **Python, C#, and PySide6**.

Whether you lost your game progress or simply want to explore everything the games have to offer, this tool allows you to instantly modify and manage save files across the **Five Nights at Freddy's** franchise.

With just a few clicks, you can **unlock nights, get max stars, earn completion certificates, modify game progress, and trigger hidden easter eggs** across the supported games.

🎮 **Now featuring 17 game configurations!**

The editor has been expanded to support fan-favourite titles such as **FNAF Jr's**, **Five Nights at Candy's (FNAC)**, and many other fangames — bringing the total to **17 unique supported configurations**.

---

## 🌟 Supported Games & Features

The FNAF Save Manager supports standard `.ini` save files generated by the **Clickteam Fusion** engine for the following titles:

* 🐻 **FNAF 1, 2, 3 & 4**

  * Unlock Night 5
  * Unlock Night 6
  * Unlock Custom Night / Night 7
  * Unlock 3-Star profiles

* 🕹️ **FNAF 5: Sister Location**

  * Modify progression
  * Unlock difficult sections
  * Unlock the Private Room
  * Modify completion progress

* 🍕 **FNAF 6: Freddy Fazbear's Pizzeria Simulator**

  * Edit Faz-Rating
  * Modify cash
  * Unlock certificates
  * Modify progression

* ⭐ **Ultimate Custom Night (UCN)**

  * Modify high scores
  * Unlock offices
  * Unlock cutscenes
  * Modify progression

* 🧩 **Fangame Expansions — 17 Configurations**

  * Dedicated save-modification logic
  * Support for community fangames
  * Includes titles such as **FNAF Jr's** and **Five Nights at Candy's (FNAC)**

## 📂 Where Are FNAF Save Files Located?

The FNAF Save Manager automatically detects supported game data whenever possible.

If you need to locate the files manually, standard Clickteam Fusion FNAF save data is commonly stored in:

```text
C:\Users\YOUR_USERNAME\AppData\Roaming\MMFApplications
```

The exact location may vary depending on the game and installation.
